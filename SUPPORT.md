# Support

## Asking a question

Open an issue on the repository your question is about, and say what you were
trying to do rather than only what went wrong. There is no separate forum —
GitHub Discussions is not enabled here, so the issue tracker is the one place
to ask.

Check the repository's `README.md` first. Every published package documents its
own options and usage there, and it is kept current with the code rather than
written once.

## Reporting a bug

Open an issue, using the bug report form where the repository offers one. A
report that names versions gets answered faster than one that does not, and
some repositories cannot act on a report without them — the plugin
repositories in particular need to know which bundler and which Node.

## Reporting a vulnerability

Do not open an issue. See [SECURITY.md](SECURITY.md) for the private reporting
channel.

## Reporting a code of conduct violation

Email **conduct@kansolabs.org**. See
